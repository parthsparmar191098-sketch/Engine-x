# Engine-X

An interactive 3D atlas of engines and heavy machinery — inline-four, turbofan, radial, wankel, turbocharger, gearbox, differential and wind turbine — modeled part by part in Three.js, with sectioning, exploded views, X-ray mode and true kinematics.

## Structure

Everything lives at the repo root (no subfolders — easiest for uploading from a phone):

- `index.html` — cinematic homepage (trailer, founder credit, links into the atlas)
- `atlas.html` — the interactive 3D atlas itself
- `styles.css`, `main.js`, `viewer.js`, `geom.js`, `materials.js`, `machines-index.js`, plus one file per machine — the atlas's code

## Deploying to GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: `main`, Folder: `/ (root)` → Save.
